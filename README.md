**Sobre o Projeto**
O Dartpedia2 é uma aplicação de linha de comando (CLI) desenvolvida em Dart como parte das atividades práticas do meio de aprendizagem dev "Dart Learn" a partir da Tarefa 1 "Crie seu primeiro aplicativo". O projeto tem como objetivo aplicar os conceitos estudados ao longo das lições por meio da criação de um sistema capaz de receber comandos do usuário e fornecer informações de forma organizada.

Atualmente, o projeto conta com comandos básicos de suporte e com a estrutura inicial para futuras funcionalidades de pesquisa e consulta de dados.

---

**Pré-requisitos**
Antes de executar o projeto, certifique-se de possuir os seguintes recursos instalados:
* Dart
* Terminal de comandos (Prompt de Comando, PowerShell ou Terminal Linux)
* Flutter
* Git (opcional, para clonar o repositório)

**Objetivos de Aprendizagem**
Durante o desenvolvimento do Dartpedia2 estão sendo aplicados conceitos estudados nas primeiras lições do Dart Learn, incluindo:
* Variáveis e tipos de dados;
* Operadores;
* Estruturas condicionais;
* Estruturas de repetição;
* Funções;
* Manipulação de argumentos da linha de comando;
* Organização de código em múltiplos arquivos;
* Desenvolvimento de aplicações CLI com Dart.
